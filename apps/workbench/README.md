# Plaq Workbench (apps/workbench)

OS-like 4-panel web UI for Plaq-OS: file tree, editor/terminal/Pareto
canvas, inspector with approvals, and event logs. Served by the FastAPI
app (`plaq_api.app`) at `/` with static mounts for `/css`, `/js`, `/assets`.

Open `http://127.0.0.1:8000/` after starting the server.
